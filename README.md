# Noob Wifey 🍳

A cozy meal-planning and grocery app for busy people who like a plan.

Plan your week's meals on a calendar, and the ingredients flow straight to a
smart shopping list — grouped by grocery aisle, with pantry staples you already
own hidden automatically. Cook smarter → shop smarter → repeat. 🔁

## Features

- 📖 **Cookbook** — save recipes (with an Instagram link, photo, ingredients & steps). Mark any recipe **Healthy** for a badge. Ships with 21 simple, healthy starter recipes.
- 🗓️ **Meal Plan** — a weekly calendar with breakfast / lunch / dinner slots.
- 🛒 **Shopping** — auto-built from your planned meals, grouped by aisle, with a progress ring. Pantry staples are hidden so you only buy what you need.
- 🫙 **Pantry** — track the staples you keep on hand.
- 🏠 **Home** — a warm daily glance: what's up next, what's left to buy.

Everything is stored locally in your browser — no account, no backend.

## Tech

Vue 3 + Vite. State lives in a reactive store persisted to `localStorage`.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL (default `http://localhost:5273`).

## Build

```bash
npm run build
npm run preview
```
